Biomedical literature intelligence

Powered by PubMed. Enhanced by AI.

Evidence-grounded retrieval over locally indexed abstracts. Answers retain PMID citations so researchers can trace claims back to source literature.

Question

A natural-language biomedical question, optionally scoped to a research domain.

Query expansion

Related query variants reduce the chance that relevant evidence is missed due to wording.

Vector search

Embeddings match against per-domain FAISS indexes and merge candidates by PMID.

Hybrid search

BM25 keyword retrieval is fused with vector results for domain searches.

Re-ranking

Candidate abstracts are re-scored before evidence reaches the model.

Knowledge graph

Optional Neo4j context adds linked biomedical entities.

Answer generation

A locally hosted model writes from retrieved abstracts.

PMID citations

Passages retain PubMed identifiers so evidence can be traced.

Indexes are being re-embedded to 1024 dimensions. View live re-indexing progress ↗

Core capabilities

Built for real science, not demos

Reliability, traceability, portability, and evidence remain first-class requirements across the platform.

⬡

Agentic AI reasoning

LangGraph orchestration and retrieval-augmented assistants bridge deterministic bio-computation with evidence-grounded interpretation.

◈

Workflow agnostic

Native support for WDL, Nextflow, Snakemake, and CWL across local, cloud, and HPC execution.

◎

GPU-accelerated stack

NVIDIA PyTorch and CUDA support high-performance learning for multi-omics and drug-discovery workloads.

⬕

End-to-end provenance

Model Registry and LIMS-X metadata connect raw inputs, workflow execution, and reported results.

◇

Reliability-first design

Short-lived tokens, role-based access control, auditable operations, and automated service testing.

⚙

Modular pipeline system

Composable workflow steps can be customized or replaced without losing reproducibility.

☁

Cloud and HPC ready

Consistent execution across laptops, Slurm clusters, AWS, Azure, and GCP.
